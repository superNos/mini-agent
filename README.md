# mini-agent-builder

`mini-agent-builder` 是一个可视化智能体内核创建器。用户可以在页面里配置模型接口、选择工具、编写系统提示词、试跑智能体、查看完整执行轨迹，并生成一个可以独立运行的 Next.js 智能体项目。

## 版本范围

已包含：

- OpenAI 兼容模型配置
- 系统提示词编辑器
- `calculator` 和 `current-time` 工具
- 空的技能扩展点
- 页面试跑智能体
- 执行轨迹可视化
- 生成项目到 `generated/<project-slug>/`

暂不包含：

- 网页搜索
- 智能体预设
- 内置角色型技能
- 检索增强生成
- 长期记忆
- 登录系统
- 云端部署

## 运行创建器

```bash
npm install
npm run dev
```

打开 `http://localhost:3000`。

## 生成项目

在创建器页面配置项目，点击“生成项目”。生成结果会写入：

```text
generated/<project-slug>/
```

生成后的项目是独立 Next.js 全栈项目，不依赖创建器运行。

## 智能体基本组成

- 模型：OpenAI 兼容的对话模型适配层。
- 工具：智能体可以调用的类型化函数。
- 技能：可扩展的提示词和工具组合入口，当前版本默认不内置业务技能。
- 循环：模型输出、可选工具调用、工具观察结果、继续循环。
- 执行轨迹：每一步模型输出、工具输入输出、最终答案或错误的可视化记录。
