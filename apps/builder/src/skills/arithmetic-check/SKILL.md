# 算术校验

## 什么时候使用

当用户问题包含算术表达式、金额汇总、比例计算、预算加减或明确要求计算时，使用这个技能。

## 执行方式

1. 先判断问题里是否有需要精确计算的表达式。
2. 如果需要计算，调用 `calculator` 工具，不要只凭模型估算。
3. 把工具返回的结果作为事实来源，再组织最终回答。
4. 如果表达式不完整，先说明缺少哪些数字或条件。

## 回答要求

- 不要编造计算结果。
- 最终回答里说明关键计算式和结果。
- 如果工具报错，解释是哪一段表达式不符合支持范围。
