# 旅行计划

## 什么时候使用

当用户要求制定旅行计划、周末出游安排、城市短途行程或预算内游玩建议时，使用这个技能。

## 执行方式

1. 先确认或提取目的地、人数、天数和预算。
2. 调用 `weather-forecast` 查询目的地天气，用天气结果判断是否需要室内备选。
3. 根据用户给出的预算和费用假设调用 `budget-check`。如果用户没有给具体费用，可以先使用保守估算，并在回答里标明是假设。
4. 调用 `itinerary-planner` 生成每日行程结构，把天气摘要和预算状态传进去。
5. 最终回答里按“假设、天气影响、预算状态、每日安排、注意事项”组织。

## 回答要求

- 不要编造实时票价、酒店库存、景点营业状态或门票价格。
- 如果缺少预算、人数或天数，说明默认假设。
- 行程安排要保持轻量，不要把每天塞满。
- 让用户能从 Trace 里看出模型为什么调用每个工具。
